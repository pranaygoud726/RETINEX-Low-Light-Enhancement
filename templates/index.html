THE TECHNOLOGY

How Retinex works

Retinex models an image as the product of illumination and reflectance.

I(x,y) = R(x,y) × L(x,y)

01 — Log Transformation

Converts multiplication into addition using logarithms.

02 — Illumination Estimation

Gaussian filtering estimates the illumination component.

03 — Reflectance Extraction

The reflectance component is calculated to reveal image details.

04 — Image Enhancement

The enhanced image is generated with improved visibility and natural colour preservation.

SSR vs MSR

Single-scale Retinex

Uses one Gaussian scale to estimate illumination. It is simpler and faster.

Multi-scale Retinex

Combines multiple Gaussian scales for more balanced enhancement across different image details.

About RETINEX

RETINEX is a Digital Image Processing project designed to improve visibility in low-light images.

Technologies: Python, Flask, OpenCV, NumPy, HTML and CSS.
